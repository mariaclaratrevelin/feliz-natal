# Feliz Natal 🎄

## 📝 Sobre o projeto

O projeto **Natal** consiste no desenvolvimento de um site informativo sobre uma das celebrações mais tradicionais do mundo. A página apresenta conteúdos sobre a história e o significado do Natal, as comemorações no Brasil e as principais tradições natalinas.

Além das páginas informativas, o site conta com uma página dedicada a um formulário, permitindo explorar diferentes tipos de campos e elementos de interação.

O projeto foi desenvolvido com o objetivo de colocar em prática os conhecimentos adquiridos em aula, especialmente sobre **overflow e formulários (forms)**, utilizando HTML5 e CSS3.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação das páginas, organização dos conteúdos e criação do formulário.
- **CSS3:** estilização dos elementos, definição do layout e aplicação de recursos como overflow.

## 📚 Conteúdos abordados

- Significado do Natal.
- Natal no Brasil.
- Tradições e costumes natalinos.
- Celebrações e símbolos do Natal.
- Formulários e seus elementos.
- Propriedade `overflow` no CSS.

## 🚀 Como executar o projeto

1. Clone este repositório ou faça o download dos arquivos.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em seu navegador.
4. Navegue pelas páginas e explore os conteúdos sobre o Natal.
